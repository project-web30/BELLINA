# Bellina Cosmetik — Landing Page

Landing page UTS: Bellina Cosmetik (HTML, CSS, JavaScript).

Semua file berada di satu folder (tanpa subfolder):
- `index.html` — halaman utama
- `pesan.html` — halaman pemesanan (pilih produk, shade, kirim pesanan ke WhatsApp)
- `style.css`, `script.js` — gaya dan skrip
- `*.jpg` — foto produk, tim, dan testimoni

Ganti nomor WhatsApp: buka `script.js`, ubah baris `const NO = '...'` (format `62...`).

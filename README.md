# Bellina Cosmetik — Landing Page

Landing page UTS: Bellina Cosmetik (HTML, CSS, JavaScript).

## Isi proyek
- `index.html` — halaman utama
- `pesan.html` — halaman pemesanan (pilih produk, shade, kirim pesanan ke WhatsApp)
- `css/style.css`, `js/script.js`, `assets/` — gaya, skrip, dan foto

## Ganti nomor WhatsApp
Buka `js/script.js`, ubah baris `const NO = '...'` (format `62...`, tanpa `+` atau `0` di depan).
